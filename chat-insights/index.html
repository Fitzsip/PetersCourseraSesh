Chat Insights

Look back at a WhatsApp conversation: rhythms, trends, topics and little milestones.

🔒
Your chat never leaves this device. The file is read by your browser and analysed right here. This page has no server, sends nothing, and its security policy blocks every network request, so you can switch off Wi‑Fi before opening it. Nothing is saved: closing the tab forgets everything.

iPhone
  1. Open the chat, tap the contact's name at the top.
  2. Scroll down → Export Chat → Without Media.
  3. Save to Files, then drop the .zip here.
Android
  1. Open the chat, tap ⋮ → More → Export chat.
  2. Choose Without media.
  3. Save the .txt (or .zip) and drop it here.
